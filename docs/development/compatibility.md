# Hardware tested

The [compatibility tables](../../README.md#wybierz-motocykl) list motorcycle models, their status and tested adapter firmware. With each new result, we record the motorcycle, adapter revision, starting firmware and connection type.

We tested Apple CarPlay and Android Auto on our 2024 Yamaha TRACER 9 GT+. Both worked on that motorcycle. The beta may still have bugs.

| Configuration | Observation |
| --- | --- |
| Yamaha TRACER 9 GT+ (2024), wired iPhone | The owner confirmed CarPlay video, joystick control and phone audio. |
| Yamaha LYWW20 display, wireless Android Auto | The rider confirmed the full map and joystick control with the [LYWW20 profile](android-auto.md). |
| Carlinkit CPC200-CCPA / A15W, Box Info hardware version YMA0-WN16-0003 | Tested manufacturer firmware: 2025.10.15.1127 and 2026.07.31.1733. The USB installer checks the OEM file set before writing. |

Box Info identifies the tested adapter variant. The marking on the PCB and the silicon revision are separate identifiers. A successful projection test establishes only the functions exercised in that configuration.
